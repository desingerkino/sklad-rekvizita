# Обновление до версии 4.0

Коротко: установите 4.0 поверх прежней версии. Данные остаются на месте,
программа сама обновит базу и сама проиндексирует фотографии для поиска.

## Что будет с данными

* Все предметы, категории, фотографии, аренды, клиенты, сотрудники, документы
  и настройки сохраняются. Номера и идентификаторы не меняются.
* Обновление базы — только добавления: две новые таблицы (избранное и недавние),
  четыре новых поля у фотографии и индексы. Ничего не удаляется и не
  переписывается.
* Перед обновлением базы программа сама делает копию:
  `backups\before_migration_v8_….db`. Установщик на Windows дополнительно
  откладывает `backups\before_update_….db`.
* Раздел «Машины» убран из программы. Если вы им пользовались, его данные
  остаются в базе, но в интерфейсе их больше нет.

## Windows

1. Закройте программу.
2. Запустите `SkladRekvizita_Setup_4.0.exe` и пройдите установку. Папку
   установки менять не нужно — новая версия встанет на место прежней.
3. Запустите программу и войдите как обычно.

Данные лежат отдельно от программы, в `%LOCALAPPDATA%\SkladRekvizita`, поэтому
установка и удаление программы их не затрагивают.

## macOS

1. Закройте программу.
2. Откройте `SkladRekvizita-4.0-mac-x86_64.dmg` и перетащите программу в
   «Программы», согласившись на замену.
3. Первый запуск: правый щелчок по программе → «Открыть» → «Открыть». Это
   нужно один раз: сборка не подписана сертификатом Apple (его нет), и macOS
   спрашивает подтверждение.

Данные лежат в `~/Library/Application Support/SkladRekvizita`.

## Первый запуск после обновления

* В строке состояния появится «Поиск по фото: индексация…». Программа
  пересчитывает отпечатки фотографий под новый алгоритм — по одной, в паузах
  между вашими действиями. Работать можно сразу; пока индексация не
  закончилась, поиск по фото видит не все снимки.
* У фотографий, загруженных до 4.0, исходный файл не сохранялся — у них кнопки
  «Показать исходный файл» нет. Новые фотографии хранятся вместе с исходником.

## Если нужно вернуться на 2.4

1. Установите 2.4 поверх 4.0.
2. База 4.0 открывается версией 2.4 как есть — новые таблицы и поля ей не мешают.
   Избранное и недавние в 2.4 не видны, но и не теряются.
3. Если что-то пошло не так — восстановите копию `before_migration_v8_….db`:
   Настройки → Резервные копии → «Восстановить из копии…».

## Перенос склада на другой компьютер (Windows ↔ macOS)

Обычные резервные копии зашифрованы ключом своего компьютера и на другом не
откроются. Для переезда есть файл переноса.

**На старом компьютере:** Настройки → Резервные копии → «Выгрузить склад в
файл…». Придумайте пароль (без него файл не открыть, восстановить его нельзя)
и сохраните файл `…​.skladpack` на флешку или внешний диск.

**На новом компьютере:** установите программу. На экране первого запуска
нажмите «У меня есть файл переноса склада…», выберите файл и введите пароль.
Затем войдите прежним логином и паролем.

Если на новом компьютере программа уже работала: Настройки → Резервные копии →
«Загрузить склад из файла…». Склад будет заменён содержимым файла; прежние
база и фотографии не удаляются, а откладываются в папке данных
(`photos_before_transfer_…`, `backups\before_transfer_…`).

Совет: файл переноса — ещё и полная копия склада, которая не зависит от
компьютера. Имеет смысл делать его раз в месяц и хранить на внешнем диске.
